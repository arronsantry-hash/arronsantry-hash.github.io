Watch This: privacy policy

Last updated 7 October 2026.

Watch This is a personal script used by one person, its author, to manage a playlist on his own YouTube account. It is not offered to anyone else.

What it accesses

With the account owner's permission, given through Google's sign-in screen, it uses the YouTube Data API to:

  • add videos to, and remove videos from, one private playlist on that account;
  • look up public details of videos, such as title and length.

What it stores

The sign-in token and a list of video IDs are stored only on the owner's own computer. Nothing is sent to any server other than Google's.

Sharing

No data is sold, shared or passed to third parties, and it is not used for advertising or analytics.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes the stored data.

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
